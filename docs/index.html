Designed for the boring parts

把复杂留在后台，把注意力留给对话。

启动器并不打断你的流程。它只在该出现的时候出现：第一次准备环境、版本需要确认，或在异常后帮你回到可用状态。

首启自动准备

把匹配的 Node 下载到应用自己的数据目录，再安装当前 dsh。无需配置全局环境，也不碰你现有的项目。

升级由你确认

发现新版时只提示，不擅自打断。确认升级后再切换到新版本，让每次变化都在你掌控中。

出错仍可继续

新版本启动失败时，自动回到上一个已经验证可用的版本；诊断信息也随时可以导出，方便排查。

Terminal, when you need it

也可以在终端直接使用 dsh。

完成首次启动后，在 Launcher 的「设置」→「命令行」中点击「安装 dsh 命令」。它会创建一个稳定入口，始终指向 Launcher 托管的 Node.js 和当前 dsh 版本，无需 npm install -g。

  • macOS/Linux：安装到 ~/.local/bin/dsh。
  • 首次安装后将该目录加入 PATH，再重新打开终端。
  • 以后升级或回滚 dsh，不需要重新安装这个命令。
macOS Terminal
# 首次安装后，在 ~/.zprofile 加入
export PATH="$HOME/.local/bin:$PATH"

# 关闭并重新打开终端后验证
dsh --help

让第一次启动，成为最后一次环境配置。
