设计原则
  • · 主窗口让给 dsh Web UI，壳子不抢空间
  • · 壳子功能收在托盘与独立面板
  • · 升级 / 错误使用独立窗口，不打扰主流程
  • · 所有交互遵循 shadcn-vue 视觉规范
shadcn-vue 组件映射
  • · Button · 按钮（primary/outline/ghost/destructive）
  • · Card · 卡片容器
  • · Dialog · 模态对话框
  • · Progress · 进度条
  • · Badge · 状态徽章
  • · Select / Input / Switch · 表单控件
  • · DropdownMenu · 托盘菜单
  • · Alert · 警告提示
技术栈
  • · Tauri 2.x（Rust 后端）
  • · Vue 3 + TypeScript 5
  • · Pinia 状态管理
  • · Tailwind CSS 3
  • · shadcn-vue UI 组件
  • · Radix Vue（底层原语）
色彩扩展
  • · success · 运行正常
  • · warning · 需注意
  • · info · 进行中
  • · destructive · 错误
  • · 在 shadcn 官方 token 基础上扩展
